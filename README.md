# BookingHub Android

BookingHub Android is a mobile marketplace application that connects customers with service providers. The application allows users to discover services, view provider details, make bookings, and manage appointments directly from their Android devices.

## Features

### Customer Features
- Browse available service providers
- View detailed provider profiles
- Search for services
- Make bookings
- Manage bookings
- View booking history

### Service Provider Features
- Provider dashboard
- Manage availability
- Accept and manage bookings
- View earnings
- Maintain provider profile
- Monitor booking activity

## Technology Stack

- Kotlin
- Jetpack Compose
- Android Studio
- MVVM Architecture
- Navigation Compose
- StateFlow
- ViewModel
